Front-End API — design your own chat

Six chat experiences, one Ada agent. Every card below is the exact same headless Ada AI Agent, surfaced through the Front-End API (embed2.js) — your team owns the entire UI layer, so the conversation can look and behave however your brand demands. Same reasoning, knowledge and actions underneath; a different design on top. Static design concepts, not interactive.

SE One agent, six UIs — how the Front-End API works
▾
// All six cards above are the SAME Ada agent. The Front-End API
// (embed2.js) is HEADLESS — Ada gives you the conversation engine,
// your team renders 100% of the UI. Only the design layer differs.

import AdaEmbed from "@ada-support/embed2";

await AdaEmbed.start({
  handle: "ada-bank",        // one agent behind every UI
  toggleCallback: openMyChat, // bottom-sheet / full-screen / bubble…
  adaReadyCallback: render    // you draw the bubbles, cards & inputs
});

// Bottom-sheet, full-screen, floating launcher, inline panel,
// record cards and multimodal upload are all just YOUR markup
// around the same reasoning, knowledge and Actions underneath.
